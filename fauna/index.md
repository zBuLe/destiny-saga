# Fauna Index

## Southern Snowfields — Terrestrial

- [emperor-bear](emperor-bear.md) : apex predator, polar bear x emperor penguin, feathered. Fully developed.
- [black-tip-snow-ferret](black-tip-snow-ferret.md) : small furred critter, bidirectional tail deception. Developed.
- [dog-horse](dog-horse.md) : very large sled dog, main transport. Draft animal. Briefly described.
- [snow-cat](snow-cat.md) : owl-based cat, berry farm guard, pest control. Mentioned.
- [snowfield-herbivore](snowfield-herbivore.md) : hadrosaur-bison hybrid, furred, white with blue pearlescent horns, winter huddle. Sketched.
- [small-bear](small-bear.md) : sloth bear / honey bear type. Mentioned.
- [snowfield-wolverine](snowfield-wolverine.md) : honeybadger / wolverine type. Mentioned.
- [snowfield-rabbit](snowfield-rabbit.md) : critter. Mentioned.
- [snowfield-lemming](snowfield-lemming.md) : critter. Mentioned.
- [snowfield-fox](snowfield-fox.md) : hunter. Mentioned.
- [big-swimming-bird](big-swimming-bird.md) : large penguin type. Mentioned.
- [small-swimming-bird](small-swimming-bird.md) : small penguin type. Mentioned.
- [gull-hawk](gull-hawk.md) : flying bird. Mentioned.
- [snowfield-condor](snowfield-condor.md) : very large flight bird. Mentioned.
- [blue-boar](blue-boar.md) : no detail. Mentioned.
- [ice-ant](ice-ant.md) : one of few snowfield insects, bioluminescent, lives on buried bush trunks, ferret prey. Briefly described.

## Southern Snowfields — Marine / Coastal

- [snowfield-whale](snowfield-whale.md) : wild, calves hunted by emperor bears. Mentioned.
- [snowfield-fish-schools](snowfield-fish-schools.md) : emperor bear prey in feeding waters. Mentioned.
- [giant-crab](giant-crab.md) : near hydrothermal vents. Mentioned.
- [snowfield-krill](snowfield-krill.md) : near hydrothermal vents. Mentioned.
- [ice-island-wolf](ice-island-wolf.md) : predator on sea ice island, competes with emperor bears. Mentioned.

## Ma Hir — Domestic Marine

- [sea-cow](sea-cow.md) : manatee analogue, gentle giant, meat / blubber / leather, grazes seagrass. Described.
- [sea-horse-mount](sea-horse-mount.md) : dugong analogue, mount / carriage puller, chariot warfare. Described.
- [sea-dog](sea-dog.md) : seal analogue, loyal companion, limited land use. Described.
- [sea-cat](sea-cat.md) : otter analogue, independent, pest control, land and water. Described.
- [sea-ox](sea-ox.md) : small domesticated whale, transport / plowing / meat / leather. Described.
- [sea-songbird](sea-songbird.md) : seahorse analogue, small colorful pet, caged, melodious. Described.
- [land-shark](land-shark.md) : legged shark, mount / cart puller / guard, wolf to bear size, land and water capable. Described.
- [sea-plesio](sea-plesio.md) : plesiosaur, surface mount, flotilla use, essentially a boat. Described.
- [sea-turtle-hauler](sea-turtle-hauler.md) : sea turtle, heavy surface hauler, flotilla use. Described.
- [sea-croc](sea-croc.md) : crocodile analogue, meat / eggs / leather, coastal and flotilla. Mentioned.
- [sea-gator](sea-gator.md) : alligator analogue, meat / eggs / leather. Mentioned.
- [sea-caiman](sea-caiman.md) : caiman analogue, meat / eggs / leather. Mentioned.
- [shellfish](shellfish.md) : oysters / mussels / clams, cultivated for meat / shells / perlite / pearls. Described.
- [sea-crustacean](sea-crustacean.md) : chicken analogue, meat / perlite / shells / eggs. Described.
- [domestic-fish-schools](domestic-fish-schools.md) : harvested for meat / bones / scales. Mentioned.
